## Hướng dẫn kiểm tra
1. Truy cập trang chủ và chọn Lab; mở trang Exercise tương ứng.
2. Bấm nút/thực hiện thao tác trên trang để quan sát kết quả.
3. Với Exercise 8.5 và 9.6, bật DevTools (F12) để xem Console và debugger.
4. Với Exercise 10.9 và 10.10, cần HTTP Server hoặc GitHub Pages để JSON được tải đúng; không mở bằng giao thức file://.

## Tự đánh giá
Em học được cách tạo dữ liệu động bằng biến, mảng, hàm và object; bắt sự kiện và kiểm tra form bằng DOM; tạo hiệu ứng và xử lý GET Request bằng jQuery. Các kỹ thuật này có thể áp dụng vào trang tìm kiếm salon, biểu mẫu đặt lịch và giỏ hàng trên website TMĐT. Em cần tiếp tục luyện kiểm thử, xử lý tình huống lỗi và tổ chức mã nguồn.
