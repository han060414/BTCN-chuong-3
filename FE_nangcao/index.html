PHẦN 01 · JAVASCRIPT CONSOLE

Thay đổi trò chơi Chrome Dino

Truy cập chrome://dino, mở Developer Tools (F12) → Console rồi sử dụng JavaScript để can thiệp vào trò chơi.

  • Đổi tốc độ chạy bằng setSpeed().
  • Đổi độ cao nhảy bằng setJumpVelocity().
  • Thay thế hàm gameOver để thử nghiệm cơ chế kết thúc trò chơi.
Runner.getInstance().setSpeed(10000);
Runner.getInstance().tRex.setJumpVelocity(20);
Runner.getInstance().gameOver = function() {};

Kết quả: Các lệnh dùng Runner.getInstance() được thực thi trong Console mà không báo lỗi. Hai lệnh đầu trả về undefined, là giá trị trả về bình thường.

PHẦN 02 · HTML & CSS

Thiết kế giao diện Responsive

Tạo trang Bai1.html gồm hai vùng nội dung LEFT (màu xanh, 70%) và RIGHT (màu đỏ, 30%).

  • Dùng @media để điều chỉnh bố cục theo độ rộng màn hình.
  • Ở màn hình tối đa 768px, hai cột được chuyển sang chiều rộng 100%.
  • Ẩn vùng RIGHT trong khoảng 321–479px và ẩn vùng LEFT ở chế độ in.
  • Dùng <picture> để chọn ảnh theo kích thước màn hình.

KIẾN THỨC TRỌNG TÂM

Media Queries hoạt động thế nào?

Media Queries giúp CSS áp dụng những quy tắc khác nhau tùy theo thiết bị, chiều rộng màn hình hoặc chế độ in. Nhờ đó, giao diện có thể hiển thị phù hợp trên máy tính và điện thoại.

@media only screen and (max-width: 768px) {
  .left, .right { width: 100%; }
}
@media only print {
  .left { display: none; }
}
